# R 地址转经纬度

把地址表转成保留原始行、解析状态与坐标系说明的经纬度表。用户只需给项目、文件和目的；读取文件能确定的信息直接检查，含义不明的关键参数再询问。

## 项目与环境

使用明确的项目根目录，默认补齐 Project.Rproj、00_admin、01_data/raw、01_data/derived、02_code、03_output；已有其他约定时适配。原始文件只读。代码与配置放 02_code，结果表放 derived，检查报告放 output。输出已存在时使用新运行目录或版本名。

检查 Rscript 的 PATH，Windows 再检查 R-core 注册表 InstallPath 或用户路径，并实际运行 --version；不能把“未找到”说成“没有安装”。检查所需包，说明缺失依赖；不能静默改用其他语言或云端。运行地点和是否实际运行要明确。中文路径问题仅在当前进程验证 UTF-8 locale，不修改全局配置。

## 执行

1. 阅读 [workflow.md](references/workflow.md)，检查真实列名、文件编码、Excel 工作表、地址上下文和唯一行标识。编号按字符保留；默认保留所有原列。
2. 参数集中在模块0：输入、地址列、城市/省份、服务商、密钥环境变量名、输出坐标系、节流与重试、备选查询。技术默认值直接记录；城市不明、服务商不明或坐标精度要求不明时澄清。
3. 地址准备和结果回填可使用 [helpers.R](scripts/helpers.R)；先复制到项目 02_code 的本次运行目录，再生成完整项目 R 脚本。脚本模块依次为配置、导入、清洗、查询、核验、输出。辅助函数不是在线 API 客户端；在线查询代码须按实际服务商文档生成。
4. 查询前说明将发送哪些地址字段给哪个服务商；遵循已有授权，仅发送查询所需字段。API Key 从进程环境读取，不向用户索取明文来写入代码，也不输出含 Key 的请求 URL。
5. 相同查询只请求一次再回填全部原始行；失败、空地址和多候选都保留。结果不满足要求时生成待复核表，不能伪造坐标。
6. 核对原始/输出行数、ID 顺序、状态总数、坐标范围和坐标系；报告唯一查询数、成功/失败/待复核数、实际调用数和文件路径。转换成地图点以前核对坐标系。

## 坐标边界

GCJ-02、BD-09、WGS84 分开记录。高德结果不能通过设置 EPSG:4326 就变成 WGS84；sf::st_transform 也不能自动解决偏移坐标转换。需要 WGS84 时保留服务原坐标，记录已验证的转换方法及误差限制；未实现或未验证转换时明确输出不是 WGS84。百度和腾讯须核对其具体接口的参数和返回约定。

## 快速试用

用户示例：“使用 $r-geocode-addresses，读取项目 raw 中的机构地址表，保留机构编码，通过高德解析地址；先给我地址检查和调用计划。”

离线示例：`Rscript scripts/demo.R 新的演示项目目录`（在本 Skill 目录运行）。示例使用合成响应，不联网，不消耗 Key，不能据此宣称在线查询或坐标转换已验证。

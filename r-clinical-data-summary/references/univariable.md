# 可选单变量分析

只在用户要求时执行。二分类结局可使用单预测变量Logistic；连续、计数、生存或配对结局需要对应模型，本模块不强行转成二分类。明确结局时点、事件/非事件编码、预测变量时点与单位、分类参照和分析单位。重复个体、复杂抽样、聚类数据不能直接使用独立观察模型。

显式创建 outcome_event=1/0。不要依赖factor排序决定事件方向。每个模型单独取结局+该预测变量的完整病例，保存 n、事件数、缺失排除数、收敛与错误状态。ID、结局自身、事件后的变量不自动进入预测变量列表。

比较空模型和单变量模型时使用完全相同数据行，整体P值可用似然比检验。多分类预测变量给整体P值及每个水平对明确参照的OR/95%CI。连续变量默认每1个已标明单位，若每10单位或标准差，明确缩放。置信区间方法要记录；若采用Wald近似说明方法，稀疏数据和分离时不能正常展示无效估计。

捕获警告而不只是异常：完全/准完全分离、未收敛、系数/标准误非有限、秩亏、无事件或全事件、预测变量无变异。失败输出“无法可靠估计”及原因，不能静默丢掉变量。更换Firth/精确/惩罚方法须基于数据和用户目的说明选择，不擅自扩大分析。

Cohen's h、SMD仅用户需要时追加，明确公式/方向/分母；不固定通用临床重要性阈值。多重比较如未调整应注明探索性；不自动按P<0.05筛选多变量模型。

交付 univariable_results.csv、所需Word三线表与诊断记录。列至少含 variable、level、reference、effect_unit、OR、CI_low、CI_high、P_overall、n、events、model_status。解释OR是比值比，不是风险比，也不把观察性关联称为独立危险因素。

API细节以实际安装R为准：stats::glm、stats::anova、stats::confint。优先查看本机help与包版本；参考 [R glm文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/glm.html)。

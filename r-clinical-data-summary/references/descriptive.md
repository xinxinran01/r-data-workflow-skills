# 描述性表格

明确分析单位、分组变量和时间点；区分受试者人数与记录数。变量顺序优先用户指定，其次字典顺序；ID、姓名、原始地址不默认进入统计表。

分类变量以 n(%) 表示，默认分母为该变量该组的非缺失N，并单列缺失；需要全组N作分母时明确配置和表注。保留字典中零计数水平，N=0时百分比为NA。全缺失且没有定义水平时，先提供字典水平或单独输出缺失审计，不能输出空表隐藏缺失。总体列和分组列使用一致规则，分组缺失者是否纳入总体需要记录。

连续变量默认中位数(Q1,Q3)，可按变量指定均值±SD，或在探索阶段同时给出两类；若用户指定自动选择，结合分布、异常值、样本量与研究约定记录规则。不能仅以Shapiro P值自动决定所有方法。有效N为0时所有统计量NA，为1时SD为NA，常量列SD为0；不对常量做Shapiro。

只要描述统计时不加假设检验P值或回归。分组比较若用户明确要求，应匹配独立/配对/重复测量设计并解释方法，不直接套模板。

## Word交付

用officer/flextable或环境已有可靠方案，分类/连续两张表可合并到同一Word。列包括变量、水平/统计类型、总体、各组、缺失信息；P值、OR仅在相应模块要求时加入。默认三线表，数值统一小数位，中文使用实际可用字体，英文可Times New Roman；字号/横竖页按列数调整。

输出 descriptions.docx 到03_output，并保留机器可读CSV。表注写统计形式、百分比分母、缺失策略、分组缺失处理。检查所有变量被正确纳入、分母一致、分组总数、标签/单位及渲染后页面。没有Word渲染工具时，完成内容核验并说明版式未做视觉检查，不用CSV冒充已交付Word。
